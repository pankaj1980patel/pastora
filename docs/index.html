Master passwordArgon2id key derivation (64 MiB, 3 passes)
Touch IDThe vault key is stored in the macOS Keychain and released only after a fingerprint check
Clipboard safetyCopied secrets are marked concealed, kept off Universal Clipboard, and cleared after 30 seconds

Frequently asked questions

Is Pastora free?

Yes. Pastora is free and open source under the MIT license.

Does Pastora send my clipboard anywhere?

No. Pastora makes no network requests. Your history, pins and secure clips are stored only on your Mac.

How are passwords in Secure Clips protected?

Each entry is encrypted with XChaCha20-Poly1305 using a vault key protected by your master password (Argon2id). You can unlock with Touch ID, and copied secrets are cleared from the clipboard automatically.

Can I reorder pinned items?

Yes. Drag pins up or down, or press ⌥↑ / ⌥↓.

How is Pastora different from Maccy or Paste?

Pastora combines clipboard history and pins with a Touch ID protected vault for credentials, so you don't need a separate app for the passwords and API keys you paste every day.

Will Pastora be available for Windows and Linux?

Yes. Linux and Windows versions are on the roadmap, built from the same Rust and Tauri codebase.
